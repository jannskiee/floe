# Triage: failure signature to likely cause to next action

Match on the exact strings; the driver records the receiver's signature
first. "Key" is the `Triage:` key a FAIL block prints (`-` for rows the
report reaches through the Versions table, a teardown note, or a SKIP or
ERROR reason that is its own account). "Retry" says
whether `audit.mjs` retries on its own. Sources are a file plus a
symbol (recorded 2026-08-29, re-anchored 2026-09-12); re-check the symbol
when a string moves. Rule zero for any connect-then-nothing: read the receiver's build
before anything else.
