first. "Key" is the `Triage:` key a FAIL block prints (`-` for rows the
report reaches through the Versions table or a teardown note). "Retry" says
whether `audit.mjs` retries on its own. Sources are
`file:line` at the time of writing (2026-08-29); re-check them when a string
moves. Rule zero for any connect-then-nothing: read the receiver's build
