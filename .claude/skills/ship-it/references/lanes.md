# CI lanes

Job names are the `name:` fields in .github/workflows/ci.yml; verify against the file when it changes. Every lane below is a `needs` of `CI green`, so any of them failing blocks the merge. Commands are for the PowerShell tool from the repo root. pnpm is not on PATH here; `corepack pnpm` is, and it must run from inside client/ (the root has no packageManager pin, so from the root corepack runs pnpm 11.7.0, which refuses client's 11.1.2 pin).

| Touched                                                                                                                         | CI job (ci.yml)                                                                                                  | Local, from repo root in PowerShell                                                                                                                                                                                                                                              | Only CI can arbitrate                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| docs/\*\* only                                                                                                                  | `Detect changed paths`, then every heavy job skips (docs lane: `CI green` in 13-33 s wall time)                  | `node .claude/skills/docs-verify/scripts/docs-check.mjs`                                                                                                                                                                                                                         | Mintlify preview deployment, Mintlify Grammar linter (Vale)                                                   |
| client/\*\*                                                                                                                     | `Build & Lint` (Node 22, pnpm)                                                                                   | `Push-Location client; corepack pnpm install --frozen-lockfile; corepack pnpm lint; corepack pnpm test; $env:NEXT_PUBLIC_SOCKET_URL='https://api.floe.one'; corepack pnpm build; node scripts/check-titles.mjs; Pop-Location` (the install is mandatory after any branch switch) | `E2E (browser + CLI interop, <os>)` x3, `Back-compat (HEAD vs latest release)`, `Docker (self-hosting stack)` |
| server/\*\*                                                                                                                     | `Server (Node.js)` (Node 20)                                                                                     | `npm --prefix server ci; npm --prefix server test` (local Node is 22; CI tests on 20)                                                                                                                                                                                            | `E2E` x3, `Back-compat`, `Docker (self-hosting stack)`                                                        |
| cli/\*\*                                                                                                                        | `CLI (Go, <os>)` x3 (Go 1.25), plus `Desktop (Wails, windows-latest)` because the desktop app imports cli/engine | `Push-Location cli; go vet ./...; go test -count=1 ./...; go build ./cmd/floe; Pop-Location`                                                                                                                                                                                     | the other two OSes, `E2E` x3, `Back-compat`                                                                   |
| desktop/\*\*                                                                                                                    | `Desktop (Wails, windows-latest)`                                                                                | `Push-Location desktop/frontend; npm ci; npm test; npm run build; Pop-Location; Push-Location desktop; go vet ./...; go test -count=1 ./...; Pop-Location` (frontend build first, always: main.go embeds frontend/dist)                                                          | `wails build -nsis`, NSIS installer, `pack.ps1` MSIX packaging smoke                                          |
| .github/workflows/**, .github/scripts/**                                                                                        | `Lint workflows` (actionlint + shellcheck) plus the full suite                                                   | `actionlint -color` (installed here as a scoop shim)                                                                                                                                                                                                                             | shellcheck (not installed here), everything else                                                              |
| anything else (README.md, CONTRIBUTING.md, SELF_HOSTING.md, DESKTOP.md, .claude/**, docker-compose.yml, unraid/**, coturn/\*\*) | full suite (the classifier is negation-based: not under docs/ means code)                                        | `docs-check.mjs` for markdown; otherwise nothing runs on these files locally                                                                                                                                                                                                     | everything                                                                                                    |

Notes:

- A rename between docs/ and a code path always classifies as code (`--no-renames` in the classifier).
- A `workflow_dispatch` or push event is always the full suite, whatever it touched.
- `E2E` and `Back-compat` upload a Playwright evidence artifact on every non-canceled run; download it before re-running, a rerun overwrites it.
