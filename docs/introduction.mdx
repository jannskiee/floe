connection: no account, no upload, and nothing kept on a server.

## What you should know

**Encrypted end to end.** Every transfer runs over an encrypted WebRTC data channel, so nobody
in between can read it, Floe's own servers included. See
[Security and privacy](/security-privacy), and
[what Floe does not protect against](/how-it-works/known-limitations) for the honest other half.

**No accounts, no uploads.** The signaling server introduces the two devices and then steps out
of the way. File data never reaches it. See [How a transfer works](/how-it-works/signaling).

**No size limit from Floe on a direct connection.** Most transfers connect directly. One that has
to fall back to a relay is capped at 2 GB, and a browser on the receiving end can only take what
that browser can hold. See [File size limits](/how-it-works/2gb-limit).

**Every file is checked on arrival.** The receiving side compares each file with the size the
sender announced, and with its SHA-256 when the sender provides one, and discards a file that does
not match. See [File checks](/how-it-works/file-checks).

**Request links, in Beta.** Floe Desktop can make a link that works the other way around: whoever
opens it sends files to your PC from their browser, with nothing to install. See
[Request links](/desktop/request-links).
