connection: no account, no upload, and nothing kept on a server.

## Pick a Floe

There are three: the web app, Floe Desktop and the `floe` [CLI](/glossary#cli), a command you type in
a terminal. All three send to each other in any direction, so this is a question of convenience
rather than compatibility.

<Columns cols={3}>
  <Card title="Web app" icon="globe" href="/web-app/sending">

## What you should know

**Encrypted [end to end](/glossary#encrypted-end-to-end).** Your files are encrypted on your device
and decrypted only on the other one, so nobody in between can read them, Floe's own servers
included. That rests on one piece of trust, explained under
[The signaling server is trusted to introduce you honestly](/how-it-works/known-limitations#the-signaling-server-is-trusted-to-introduce-you-honestly).
The connection is a [WebRTC](/glossary#webrtc) [data channel](/glossary#data-channel). See
[Security and privacy](/security-privacy), and
[what Floe does not protect against](/how-it-works/known-limitations) for the honest other half.

**No accounts, no uploads.** Floe's server, the
[signaling server](/glossary#signaling-server), only introduces the two devices and then steps out
of the way. File data never reaches it. See [How a transfer works](/how-it-works/signaling).

**No size limit from Floe on a direct connection.** Most transfers connect
[directly](/glossary#direct-connection). One that has to fall back to a [relay](/glossary#relay) is
capped at 2 GB, and a browser on the receiving end can only take what that browser can hold. See
[File size limits](/how-it-works/2gb-limit).

**Every file is checked on arrival.** The receiving side compares each file with the size the
sender announced. When the sender provides one, it also compares a fingerprint of the contents, its
[SHA-256](/glossary#sha-256). A file that does not match is discarded. See
[File checks](/how-it-works/file-checks).

**Request links.** Floe Desktop can make a link that works the other way
around: whoever opens it sends files to your PC from their browser, with nothing to install. See
[Request links](/desktop/request-links).
