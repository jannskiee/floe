Every keyboard shortcut in Floe Desktop for Windows, with the places where each one does nothing.

**Needs:** Floe Desktop on Windows. See [Installation](/desktop/installation).

| Shortcut | What it does | Where it does nothing |
|---|---|---|
| `Ctrl` `O` | Adds files. Leaves Settings or History, switches to **Send** and its **Files** tab, then opens the file picker. | While the cursor is in a text field, while a send or a receive by code is running, and behind a dialog. |
| `Ctrl` `Enter` | The current tab's main action: **Send** on the Send tab, **Receive** on the Receive tab's **Code** view. Inside the **Text** box it sends the note, and inside **Code or link** it starts the receive. | In other text fields, in Settings and History, during a send or a receive by code, behind a dialog, with nothing to send or receive, and on **Request link**. |
| `Ctrl` `V` | Pastes files copied in File Explorer, or an image from the clipboard, into the send list. | While the cursor is in a text field, where the field takes the paste. Also during a send or a receive by code, behind a dialog, and when the clipboard holds neither files nor an image. |
| `Ctrl` `H` | Shows or hides **History**, leaving Settings if it is open. | While the cursor is in a text field, and behind a dialog. |
| `Ctrl` `,` | Opens or closes **Settings**. | Behind a dialog. Otherwise it works on every screen, also while you type. |
| `Ctrl` `R` | Starts over: cancels a send or a receive by code and clears the Send and Receive tabs. | While the cursor is in a text field, and behind the **Close Floe?** and **Reset all settings?** dialogs. |
| `Ctrl` `Z` | Undoes a **Clear**, including after its bar has gone. | Anywhere but the Send tab the clear came from, behind a dialog, and while the cursor is in a text field. |
| `Esc` | Closes whatever is on top: a dialog first, then Settings. | On the Send, Receive and History screens, where nothing is on top. It does not leave History. |
| `Enter` | In the **Code or link** field, starts receiving. | In the **Text** box it starts a new line. Use `Ctrl` `Enter` there. |

A dialog, in this table, is one of these three questions: **Start over?**, **Close Floe?** and
**Reset all settings?**. One more question is not among them: **This drop has renamed files**, which
**Show in folder** asks for a [request link drop with renamed files](/desktop/request-links#renamed-files).
`Ctrl` `O`, `Ctrl` `V`, `Ctrl` `H`, `Ctrl` `,` and `Ctrl` `R` still act behind it, and `Esc` answers it with
**Cancel**.

## Behavior worth knowing

**Most shortcuts pause while you type.** `Ctrl` `O`, `Ctrl` `V`, `Ctrl` `H`, `Ctrl` `R` and `Ctrl` `Z` do
nothing while the cursor is in a text field. So typing a code or a note is never interrupted, and a
half-typed note is never wiped mid-word. The text box also keeps its own paste and undo. `Ctrl` `Enter`
pauses too, except in the two fields that have an action of their own: the **Text** box and **Code or
link**.

**Some also pause while a transfer runs.** `Ctrl` `O`, `Ctrl` `V` and `Ctrl` `Enter` do nothing while a send
or a receive by code is running. The **Send** and **Receive** buttons are not available then either, so a
shortcut never starts something its button would refuse.

**None of them acts behind a dialog.** While **Start over?**, **Close Floe?** or **Reset all settings?** is
open, `Ctrl` `O`, `Ctrl` `Enter`, `Ctrl` `V`, `Ctrl` `H`, `Ctrl` `,` and `Ctrl` `Z` do nothing. A key cannot
change the screen behind the question. `Ctrl` `R` waits behind **Close Floe?** and **Reset all settings?**.
Behind **Start over?** it starts over only once nothing would be lost any more. Answer a dialog with its
buttons, `Enter` on the button that has focus, or `Esc`.

**`Ctrl` `,` works while you type.** It opens Settings from any screen, the way a preferences shortcut
normally does, except behind a dialog.

**Request links have no shortcut.** `Ctrl` `Enter` does nothing on the **Request link** view: no shortcut
makes a [request link](/glossary#request-link), accepts a request or declines one. To answer a request from
the keyboard, move focus to **Accept** or **Decline** and press `Enter` or `Space`. Both buttons ignore every
key and click for 1 second after the request appears, and for 1 second after the window comes back into
focus.

**`Ctrl` `Z` is the narrowest of them.** It undoes a **Clear**, and only from the Send tab that clear came
from. The undo itself waits while you look elsewhere, so going back to that tab brings it within reach
again: see [Clear and Undo](/desktop/sending#clear-and-undo). `Ctrl` `Shift` `Z` is deliberately not an
undo, because it is redo on every platform that has it.

**`Ctrl` `R` asks first when there is something to lose, and only then.** The dialog is titled **Start
over?**, and its buttons are **Keep going** and **Start over**. Which cases ask, and the sentence each one
shows, are in [Start over](/desktop/sending#start-over). Staged files never ask, because the originals are
untouched on disk. The shortcut and a click on **Floe** at the left of the title bar follow the same rules.

**`Ctrl` `R` never reloads Floe.** In a browser that key reloads the page. Floe switches reload off (its
window is a web view), so the key cannot drop a transfer that way. It only starts over, and asks first when
something would be lost.

**Holding a shortcut fires it once.** Key repeat is ignored for `Ctrl` `V`, `Ctrl` `O`, `Ctrl` `Enter`,
`Ctrl` `,`, `Ctrl` `H` and `Ctrl` `Z`, so holding paste does not flood the list.

**Four of them appear in the app.** The tooltips on the title bar's **Floe** name, the gear, the **Back**
arrow in Settings and the History clock show `Ctrl+R`, `Ctrl+,`, `Esc` and `Ctrl+H`. The others are not shown
anywhere on screen.
