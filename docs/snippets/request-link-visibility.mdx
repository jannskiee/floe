| | The person who made the link sees | The sender sees |
|---|---|---|
| IP address | The sender's, once the sender clicks **Send**, unless the sender turned on Hide my IP on the page. | The link maker's, once the sender clicks **Send**, unless Floe Desktop has Hide my IP on. |
| Floe version | Nothing about the sender's. | With `floe send --to`, the link maker's Floe Desktop version when it differs from the sender's and looks like a release, for example `Peer version: desktop-v1.0.4`. The browser page shows none. |
| Names | Not the sender's: Floe has no accounts. | Not the link maker's: the link's label never leaves the PC that made it. |
| Files | The count and total size in the request, then each file's name as it arrives. No name shows before the drop is accepted. | Their own files, which ones arrived, and why a drop stopped, such as a full drive on the other side. |
